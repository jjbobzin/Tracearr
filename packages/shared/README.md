# @tracearr/shared

Types and Zod schemas shared across the Tracearr apps (server, web, mobile).

This package is published so Tracearr's own apps can consume it outside the monorepo. It is not a stable public API: exports track whatever the current Tracearr release needs, and any version may break consumers that are not Tracearr.

Licensed under AGPL-3.0-only. Source lives in the [Tracearr monorepo](https://github.com/connorgallopo/Tracearr) under `packages/shared`.
